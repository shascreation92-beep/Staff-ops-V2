=====================================================
   STAFFOPS WORKSTATION AGENT INSTALLATION GUIDE
=====================================================

To install the agent on any Windows PC / Laptop:

1. Extract / Unzip the downloaded folder.
2. Double-click on:  Install-StaffOps-Workstation.bat
   (Or Right-Click -> "Run as Administrator")
3. Enter the Employee Email / ID when prompted.
4. Press Enter!

Done! The StaffOps agent will run silently in the background automatically.
